Glowberry

Glowberry is a 26.2 and above Minecraft server for both Bedrock and Java, with an economy, teleportation commands and much more! Start playing by clicking down below or keep reading to see why Glowberry is so good.

Features

Cross-play

Glowberry is a Java 26.2 server. However, it supports Bedrock as well, and all versions from 26.2 and above! Java and Bedrock players can seamlessly play together as if they were on the same edition.

Economy

Glowberry has a stable, cheap economy, with a balanced shop, player-driven auction house and simple way to sell! Playing becomes so much easier while also not becoming too easy with /shop.

Semi-anarchy

Glowberry is a semi-anarchy server, meaning you can kill anyone and destroy anything, but you can't hack or send NSFW content. This is so the server is fair for everyone while still being crazy and chaotic!

How to Join

To join Glowberry, follow these 2 simple steps to instantly get playing! Java and Bedrock have different ways of joining, so you'll have to choose the right step for your edition. You can tell which is right by checking what edition it's for in brackets.

Add the server (Java)
Firstly, open Minecraft, go to Multiplayer and click Add Server. For the server address, type in play.glowberry.fyi and click Done. You should now be able to join the server!
Add the server (Bedrock)
If you're on Bedrock instead, click Play, go to the Servers tab and click Add Server. For the server address, type in play.glowberry.fyi and for the port, type in 19132. Finally, click Add Server. For consoles, follow this tutorial.
Start playing!
You can now start playing! On Java, hover over the server and click the arrow on the logo. On Bedrock, click Play. Once you're in, you can do anything you want (as long as it follows the CoC).
